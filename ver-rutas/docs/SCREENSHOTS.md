# Screenshots to capture for ver-rutas

Capture with `Ctrl+Option+4` (saves to `~/Pictures/Capturas`), then move/rename into `docs/images/`.

General tips: new, clean terminal window (about 100x30 characters), full-screen Claude Code so hover works. Make Claude cite paths to a harmless demo folder (for example a sample project with README.md, a PNG and a src folder). No personal data: the paths shown contain your user name unless you use `~/`; prefer `~/` paths or a demo user, and crop the title bar.

- [ ] `docs/images/path-chips.png` - Hero image. The chip row above the prompt with one chip hovered and its preview visible (folder listing or first lines of a file). About 1000x400 px.
- [ ] `docs/images/chips-row.png` (optional) - The chip row alone with 3-4 chips (folder, text file, image).
- [ ] `docs/images/ver-command.png` (optional) - Output of `/ver` listing numbered paths, then `/ver 1`.
- [ ] `docs/images/path-chips.gif` (optional) - 10 s: hover a chip, then click it so Finder opens with the file selected. Keep the Finder window to a harmless folder.

Only `path-chips.png` is referenced by the READMEs right now.
