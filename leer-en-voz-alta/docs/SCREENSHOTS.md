# Screenshots to capture for leer-en-voz-alta

Capture with `Ctrl+Option+4` (saves to `~/Pictures/Capturas`), then move/rename into `docs/images/`.

General tips: new, clean terminal window (about 100x30 characters), a neutral prompt, a harmless project folder. No personal data: hide your user name and home path in the prompt and title bar, no real project names, no tokens. Crop to the terminal.

- [ ] `docs/images/leer-command.png` - Hero image. Claude Code after a short, harmless answer and `/leer`, showing "Leyendo la última respuesta..." (about 1000x500 px).
- [ ] `docs/images/leer-estado.png` (optional) - Output of `/leer estado` showing the settings line.
- [ ] `docs/images/leer-demo.gif` (optional) - 10 s screen recording: ask a question, run `/leer`, then `/leer stop`. A GIF cannot show sound: add a caption or mention it in the README.

Only `leer-command.png` is referenced by the READMEs right now.
